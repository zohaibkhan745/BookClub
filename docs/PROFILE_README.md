## 🚀 Featured Projects

### 📚 [Book Club](https://github.com/zohaibkhan745/BookClub)
A full-stack community platform for book lovers. Users can browse a library, share their books, borrow from others, and discuss reads in a community forum.
- **Stack:** FastAPI · React 18 · TypeScript · Tailwind CSS · PostgreSQL (Supabase) · Alembic
- JWT auth, response caching, interactive API docs, and deployed on Vercel + Render.

### 👗 [AI Fit & Try](https://github.com/zohaibkhan745/AFAT-AI-FIT-TRY-)
A virtual try-on and AI-powered size recommendation web app. Upload a photo and an outfit to preview the look, or use AI to estimate your size from body measurements.
- **Stack:** React · Vite · TypeScript · Tailwind CSS · Camera API
